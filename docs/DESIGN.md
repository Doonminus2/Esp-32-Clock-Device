# นาฬิกา LED ESP32 — เอกสารออกแบบ

ฉบับ 2.1 (2 ต.ค. 2026) — แทนที่ส่วนออกแบบใน `handoff-project-setup.md`

---

## 1. ภาพรวม

นาฬิกาตั้งโต๊ะ ESP32 + จอ LED dot matrix สีแดง 32×8 ในกล่องอะคริลิกสีดำเงา

- **4 โหมดหลัก** สลับด้วยทัช: นาฬิกา → วันที่ → จับเวลา → ปลุก
- เวลาหลักมาจาก RTC DS1302 (มีถ่าน CR2032) ส่วน WiFi + NTP ใช้ปรับเวลาให้ตรง
- ใช้งานได้แม้ไม่มี WiFi และตั้งเวลาเองได้จากเมนู
- จอแสดงตัวเลข **ม้วนขึ้น** ทุกครั้งที่หลักเปลี่ยน (แนวเดียวกับคลิปอ้างอิง)

## 2. ฮาร์ดแวร์และการต่อขา

| อุปกรณ์ | ขาโมดูล | ESP32 (DevKit V1 30 ขา) | ไฟเลี้ยง |
|---|---|---|---|
| จอ MAX7219 ×4 (32×8) | DIN / CLK / CS | GPIO23 / GPIO18 / GPIO5 (VSPI) | VIN (5V) |
| RTC DS1302 | CLK / DAT / RST | GPIO14 / GPIO27 / GPIO26 | 3V3 |
| ปุ่มกด (Enter) | OUT | GPIO25 | 3V3 |
| ทัช T1 ◀ (TTP223) | OUT | GPIO32 | 3V3 |
| ทัช T2 ▶ (TTP223) | OUT | GPIO33 | 3V3 |
| Passive buzzer | S | GPIO19 (LEDC PWM) | 3V3 |

- ห้ามใช้ GPIO6–11 (แฟลช) และ GPIO12 (strapping)
- ขาว่างสำรอง: GPIO4, 13, 16, 17
- TTP223 ค่าโรงงาน = HIGH ตอนแตะ (`active_level = 1`)
- ปุ่มกด: **ยังไม่รู้** ว่ากดแล้วได้ HIGH หรือ LOW → ให้ smoke test ของ `input` พิมพ์ค่าออกมาก่อน
- ความสว่างจอจำกัดไม่เกิน 8/15 (คุมกระแสผ่านไดโอด VIN)

## 3. Toolchain

| รายการ | ค่า |
|---|---|
| Build | PlatformIO, `platform = espressif32 @ 7.1.0` |
| Framework | ESP-IDF 6.1.0 (`framework = espidf`) |
| Board | `esp32doit-devkit-v1` |
| Lib ภายนอก | `esp-idf-lib/max7219`, `esp-idf-lib/ds1302`, `espressif/button`, `espressif/network_provisioning` |

ค่าคอนฟิกที่เราตั้งเองเก็บใน `sdkconfig.defaults` เท่านั้น ไฟล์ `sdkconfig.esp32doit-devkit-v1` ถูกสร้างใหม่ทุกครั้งและไม่ขึ้น git

## 4. โครงโปรเจค

```
components/
├── board/         ขา GPIO + ค่าคงที่ฮาร์ดแวร์ (header อย่างเดียว)
├── display/       max7219 + framebuffer 32×8 + ฟอนต์ + วาด glyph/ข้อความ
├── rtc/           ห่อ ds1302: อ่าน/เขียนเวลา, เช็กว่าเวลา valid
├── timekeeping/   เวลาของทั้งระบบ: RTC ↔ system time, TZ
├── input/         T1, T2, ปุ่มกด ผ่าน espressif/button → ส่ง event
├── buzzer/        LEDC: beep patterns, เสียงปลุก
├── settings/      NVS: 12/24 ชม., โหมดกลางคืน, ความสว่าง, เวลาปลุก
├── net/           WiFi + provisioning + SNTP + Net FSM
└── ui/            UI FSM + หน้าจอทุกโหมด + แอนิเมชัน
src/main.c         init ทุกตัว + สร้าง task
```

แต่ละ component: `CMakeLists.txt`, `include/<ชื่อ>.h` (API สาธารณะ), ไฟล์ `.c` และ `idf_component.yml` ถ้าใช้ lib ภายนอก ฟังก์ชันขึ้นต้นด้วยชื่อโมดูล เช่น `display_flush()`

**กฎการพึ่งพา**

- driver ชั้นล่าง (`display`, `rtc`, `input`, `buzzer`) ไม่รู้จักกันเอง และไม่รู้จัก `ui`
- `input` และ `net` ส่ง event ออกมา ไม่เรียก `ui` ตรงๆ
- `ui` เป็นตัวเดียวที่รู้ภาพรวม

```
            main
              │
             ui ──────────────────┐
   ┌────┬────┼──────┬─────────┐   │
display input buzzer settings  net
   │    │                       │
   │    │       timekeeping ◄───┘
   │    │           │
   └────┴── board ──┴── rtc
```

## 5. การแสดงผล

### 5.1 Layout หน้านาฬิกา (แบบ ก)

HH:MM ตัวกว้าง 4×7 + วินาทีตัวเล็ก 3×5 ชิดล่าง

| คอลัมน์ | สิ่งที่แสดง | แถว |
|---|---|---|
| 0–3 | ชั่วโมง หลักสิบ (4×7) | 0–6 |
| 5–8 | ชั่วโมง หลักหน่วย (4×7) | 0–6 |
| 10 | โคลอน | 2, 4 |
| 12–15 | นาที หลักสิบ (4×7) | 0–6 |
| 17–20 | นาที หลักหน่วย (4×7) | 0–6 |
| 22 | โคลอนเล็ก | 3, 5 |
| 24–26 | วินาที หลักสิบ (3×5) | 2–6 |
| 28–30 | วินาที หลักหน่วย (3×5) | 2–6 |
| 31 | ไฟสถานะ: แถว 0 = เปิดปลุกอยู่, แถว 7 = ออฟไลน์ (ดูคำเต็มได้ด้วยปุ่ม Enter ข้อ 5.8) | 0, 7 |

### 5.2 เอฟเฟกต์ม้วนขึ้น

- เมื่อหลักใดเปลี่ยน: ตัวเก่าเลื่อนขึ้นจาก y=0 ไป y=−8, ตัวใหม่เลื่อนจาก y=+8 ไป y=0
- 8 ขั้น × 50 ms = 400 ms ต่อการเปลี่ยนหนึ่งครั้ง
- ทุกหลักที่เปลี่ยนพร้อมกันม้วนพร้อมกัน (เช่น 12:59:59 → 13:00:00 ม้วน 5 หลัก)
- `display` ต้องวาด glyph ที่ y ติดลบหรือเกิน 7 ได้ โดยตัดส่วนที่อยู่นอกจอทิ้ง
- `ui` วาดจอใหม่ทุก 50 ms (20 fps) แล้วส่งทั้งเฟรมทีเดียวด้วย `display_flush()`

### 5.3 หน้าวันที่

- รูปแบบ: `FRI 2/10/26` (วันย่อ 3 ตัวพิมพ์ใหญ่, วัน/เดือน/ปี 2 หลัก, ไม่เติม 0 หน้าวันและเดือน)
- ข้อความกว้างเกิน 32 จุด จึงเลื่อนจากขวาไปซ้ายวนต่อเนื่อง 1 จุดทุก 50 ms
- ฟอนต์ 3×5: ตัวเลข 0–9, `/`, และตัวอักษรพิมพ์ใหญ่ที่ต้องใช้
- อยู่ในหน้านี้จนกว่าจะแตะเปลี่ยนโหมด (ไม่เด้งกลับเอง)

### 5.4 หน้าจับเวลา

- ใช้ layout เดียวกับหน้านาฬิกา: `MM:SS` ตัวใหญ่ + เศษวินาที (ร้อยละ) ตัวเล็ก
- เกิน 59:59.99 → เปลี่ยนเป็น `HH:MM` + `SS` ตัวเล็ก

### 5.5 หน้าปลุก

- แสดงเวลาปลุก `HH:MM` ตัวใหญ่ + `ON` หรือ `--` ตัวเล็กในช่องวินาที

### 5.6 ป้ายชื่อโหมด

เมื่อแตะเปลี่ยนโหมด ให้แสดงป้าย 0.8 วินาทีก่อนเข้าหน้านั้น: `CLK`, `DATE`, `STW`, `ALM`

### 5.7 ความสว่าง

- ปกติ: ตามค่าใน settings (สูงสุด 8/15)
- โหมดกลางคืน: หรี่อัตโนมัติตามช่วงเวลาที่ตั้ง (ค่าเริ่มต้น 22:00–06:00) ความสว่าง 0–1

### 5.8 ป้ายสถานะเครือข่าย

- กดปุ่ม Enter ในหน้านาฬิกา → ขึ้น `ONLINE` หรือ `OFFLINE` 2 วินาที แล้วกลับหน้านาฬิกา
- ฟอนต์ 3×5 วางกึ่งกลางจอ ไม่ต้องเลื่อน (`ONLINE` กว้าง 23 จุด, `OFFLINE` กว้าง 27 จุด)
- `ONLINE` = Net FSM อยู่ใน `NET_SYNCED`; สถานะอื่นทั้งหมดถือเป็น `OFFLINE`
- ไม่ขึ้นเองอัตโนมัติ หน้านาฬิกาจะไม่ถูกขัดจังหวะถ้าไม่ได้กด
- จุดสถานะที่คอลัมน์ 31 ยังติดตามปกติ

## 6. อินพุต

### 6.1 ตารางปุ่ม

| อินพุต | หน้าหลัก | ในเมนู / ตอนแก้ค่า |
|---|---|---|
| T1 ◀ | โหมดก่อนหน้า | ลด −1 |
| T2 ▶ | โหมดถัดไป | เพิ่ม +1 (แตะค้าง = วิ่งเร็ว) |
| ปุ่มกด สั้น | Enter (ดูตามโหมดด้านล่าง) | ยืนยัน → ช่องถัดไป |
| ปุ่มกด ค้าง 3 วิ | เข้าเมนูตั้งค่า **+ เสียง beep** | ยกเลิก ไม่บันทึก |
| ปุ่มกด ค้างตอนเสียบไฟ | ตั้งค่า WiFi **+ เสียง beep** | — |
| นาฬิกาปลุกดัง | แตะ/กดอะไรก็ได้ = หยุดเสียง | — |

- เสียง beep ดังทันทีที่ครบ 3 วินาที (ขณะยังกดค้าง) ผู้ใช้จะได้รู้ว่าปล่อยปุ่มได้แล้ว
- ใช้ `espressif/button` กับทั้ง 3 ปุ่ม: debounce, กดสั้น, กดค้างตามเวลาที่กำหนด
- `input` แปลงเป็น event: `IN_PREV`, `IN_NEXT`, `IN_PREV_REPEAT`, `IN_NEXT_REPEAT`, `IN_ENTER`, `IN_HOLD_3S`, `IN_BOOT_HOLD`

### 6.2 ปุ่ม Enter ในแต่ละโหมด

| โหมด | กดสั้น |
|---|---|
| นาฬิกา | แสดง `ONLINE` / `OFFLINE` 2 วินาที (ข้อ 5.8) |
| วันที่ | — (สำรองไว้) |
| จับเวลา | เริ่ม / หยุด |
| ปลุก | เปิด / ปิดปลุก |

### 6.3 เสียง buzzer

| เหตุการณ์ | รูปแบบเสียง |
|---|---|
| เข้าเมนูตั้งค่า (ค้าง 3 วิ) | beep สั้น 1 ครั้ง |
| เข้าโหมดตั้งค่า WiFi | beep สั้น 2 ครั้ง |
| บันทึกค่าในเมนู | beep สั้นมาก 1 ครั้ง |
| นาฬิกาปลุก | beep-beep ซ้ำ จนกว่าจะกดหยุด หรือครบ 60 วินาที |

## 7. เมนูตั้งค่า

เข้าด้วยปุ่มกดค้าง 3 วิ เลื่อนรายการด้วย T1/T2 และเลือกด้วยปุ่มกด

| รายการ | ป้าย | แก้ค่า |
|---|---|---|
| ตั้งเวลา | `TIME` | ชั่วโมง → นาที → บันทึก (วินาที = 00) |
| ตั้งวันที่ | `DATE` | วัน → เดือน → ปี → บันทึก |
| ตั้งเวลาปลุก | `ALRM` | ชั่วโมง → นาที → บันทึก |
| รูปแบบเวลา | `12H` / `24H` | สลับ |
| โหมดกลางคืน | `NITE` | เปิด/ปิด → เวลาเริ่ม → เวลาจบ |
| ความสว่าง | `BRT` | 1–8 |
| ออก | `EXIT` | — |

- ไม่มีการกดนาน 30 วินาที = ออกจากเมนู ไม่บันทึกค่าที่ยังไม่ยืนยัน
- ค่าทั้งหมดยกเว้นเวลา/วันที่ เก็บใน NVS ผ่าน `settings`
- เวลา/วันที่ เขียนลง RTC ผ่าน `timekeeping`

## 8. FSM

แยก 2 FSM คนละ task เพื่อไม่ให้การต่อ WiFi บล็อกการแสดงผล

### 8.1 UI FSM (task `ui`, รอบละ 50 ms)

| State | Event | ไป State |
|---|---|---|
| `UI_BOOT` | RTC valid | `MODE_CLOCK` |
| | RTC invalid | `WAIT_TIME` (แสดง `--:--` กะพริบ) |
| | `IN_BOOT_HOLD` | `UI_PROVISIONING` (beep 2 ครั้ง) |
| `WAIT_TIME` | Net synced | `MODE_CLOCK` |
| | Net offline | `MENU` → เข้า `TIME` อัตโนมัติ |
| `MODE_CLOCK` ↔ `MODE_DATE` ↔ `MODE_STOPWATCH` ↔ `MODE_ALARM` | `IN_PREV` / `IN_NEXT` | โหมดก่อนหน้า/ถัดไป (วนรอบ) |
| `MODE_*` | `IN_HOLD_3S` | `MENU` (beep) |
| `MODE_CLOCK` | `IN_ENTER` | `SHOW_NET_STATUS` |
| `SHOW_NET_STATUS` | ครบ 2 วิ หรืออินพุตใดก็ได้ | `MODE_CLOCK` |
| `MODE_STOPWATCH` | `IN_ENTER` | เริ่ม/หยุด (อยู่ state เดิม) |
| `MODE_ALARM` | `IN_ENTER` | เปิด/ปิดปลุก (อยู่ state เดิม) |
| `MENU` | เลือก `EXIT`, `IN_HOLD_3S` หรือ timeout 30 วิ | กลับโหมดเดิม |
| (ทุก state ยกเว้น `UI_PROVISIONING`) | ถึงเวลาปลุก และปลุกเปิดอยู่ | `ALARM_RINGING` |
| `ALARM_RINGING` | อินพุตใดก็ได้ หรือครบ 60 วิ | กลับ state เดิม |
| `UI_PROVISIONING` | Net บันทึก credentials แล้ว | `UI_BOOT` |

ตัวจับเวลาเดินต่อเบื้องหลังแม้สลับไปโหมดอื่น

### 8.2 Net FSM (task `net`)

| State | Event | ไป State |
|---|---|---|
| `NET_IDLE` | มี WiFi credentials ใน NVS | `WIFI_CONNECTING` |
| | ไม่มี | `NET_OFFLINE` |
| `WIFI_CONNECTING` | ต่อได้ | `SNTP_SYNCING` |
| | เกิน 15 วิ | `NET_OFFLINE` |
| `SNTP_SYNCING` | ได้เวลา → เขียน RTC, แจ้ง UI | `NET_SYNCED` |
| | ล้มเหลว 3 ครั้ง | `NET_OFFLINE` |
| `NET_SYNCED` | ครบ 1 ชั่วโมง | `SNTP_SYNCING` |
| | WiFi หลุด | `WIFI_CONNECTING` |
| `NET_OFFLINE` | ครบ 5 นาที | `WIFI_CONNECTING` |
| `PROVISIONING` | บันทึก credentials แล้ว | `WIFI_CONNECTING` |

Provisioning ใช้ `espressif/network_provisioning` แบบ SoftAP (IDF 6 ไม่มี `wifi_provisioning` แล้ว) ถ้าใช้ security v1 ต้องเปิด `CONFIG_ESP_PROTOCOMM_SUPPORT_SECURITY_VERSION_1=y` ใน `sdkconfig.defaults`

## 10. ประเด็นที่ยังเปิดอยู่

- active level ของปุ่มกด (รู้หลัง smoke test ข้อ 5)
- ทิศการเรียงแผ่นจอ / ต้องตั้ง `mirrored` หรือไม่ (รู้หลัง smoke test ข้อ 2)
- ปุ่ม Enter ในโหมดวันที่ยังว่าง ไว้ใช้ภายหลังได้
- เลื่อนปลุก (snooze) ยังไม่ทำในรอบแรก
